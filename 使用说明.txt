Modbus RTU 多通道采集系统 v0.8.0（Go / Wails 版）
================================================

【运行前提】
  Windows 10 / 11 x64，需要系统里有 WebView2 运行时。
  Windows 11 自带；Windows 10 一般随 Edge 装好了，
  万一提示缺少 WebView2，装一次即可（微软官网搜 "WebView2 Runtime"）。
  本版本是单文件 exe，不需要 .NET 运行时，也不需要旁边的 dll。

【怎么启动】
  双击 ModbusRtuScada.exe。首次启动需要几秒（要初始化 WebView2）。

【会生成哪些文件】（都在 exe 同目录）
  channels.json   通道与点位配置，备份配置就是备份它
  settings.json   历史落库策略（开关 / 保留天数 / 容量上限）
  history/        历史数据，按点位分目录、按天分片
  导出的 *.csv    点表、点位定义、曲线、历史、报警、日志、通信报文（UTF-8 BOM，Excel 直接打开）
  （通信报文只在内存里滚动保留，不生成文件，需要留存就导出 CSV）

【串口参数】
  支持串口号、波特率、数据位(7/8)、校验位(无/奇/偶)、停止位(1/2)、
  读写超时、轮询周期、从机号。常用 8 数据位 / 无校验 / 1 停止位（8N1）。
  通道正在采集时改了串口参数，程序会自动按新参数重连；
  只改名称、从机号、轮询周期则不断线。

【快速上手】
  1. 左侧「新增」建通道，配好 COM 口、波特率、数据位、停止位、校验位
  2. 选中通道后「新增点」：功能码 03（只读采集）/ 06、16（可写）
  3. 数据类型 UInt16 / Float32 / Double64 / Int32
  4. 选了 Float32 / Int32 / Double64 后，会出现「字节顺序」下拉（UInt16 不显示）：
     - CDAB 低字在前（默认，与旧版一致）：32 位 [CD][AB]，64 位 GH EF CD AB
     - ABCD 高字在前（大端直排）：32 位 [AB][CD]，64 位 AB CD EF GH
     - BADC 字内字节交换：32 位 [BA][DC]，64 位 BA DC FE HG
     - DCBA 全反序（小端）：32 位 [DC][BA]，64 位 HG FE DC BA
     下拉下方会写出该字序下寄存器依次是什么，对着报文一眼能核对。
     点表「类型」列也会带这个小标记（如 Float32 CDAB）。
     排查字序问题时，把实时值口径切到「寄存器」看最直观——那里显示的是
     报文里的原始寄存器，不按字序重排。
  5. 寄存器地址支持三种写法，下拉里选形式再填文本：
     - 十进制：协议地址，0 ~ 65535
     - 十六进制：0x0064 / 0064 / 64h 都行，带 0x 或 h 标记的输入强制按十六进制解释
     - PLC 地址：40001 = 协议地址 0；> 9998 时用 6 位 400001
     填非 5/6 位的 PLC 地址会报错；落到非保持寄存器区会出 ⚠ 提示，
     因为本项目功能码 03/06/16 只读写 4xxxx
  6. 「全部启动」开始采集，通道状态显示「已连接」即通
  7. 实时值可在「工程值 / 十六进制 / 二进制 / 寄存器」四种口径间切换，
     单元格点一下即复制

【写入寄存器】
  点表行点「写入」，弹出带实时预览的对话框，三种输入口径任选：

  1) 原始值（默认）
     寄存器里真正存放的十进制数值，不乘倍率、不加偏移。可带单位后缀。
  2) 十六进制
     按 IEEE754 位模式填，跟点表「十六进制」列显示的是同一套东西，
     高字节在前。下发时再按本点的字节顺序拆成寄存器。
     0x 前缀、h 后缀、空格与下划线都认，大小写不限，位数不够高位补零。
     Float32 最多 8 位，Double64 最多 16 位。
  3) 工程值
     现场读数，程序按「原始值 = (工程值 − 偏移) ÷ 倍率」反算出报文内容。
     比如点表配了 倍率 0.1 / 偏移 5，想设成 12.5 °C，
     这里填 12.5，程序自动算出原始值 75 发出去。

  - 切换口径会清空输入框：同一串文本在三个口径下含义完全不同
    （"12" 在十六进制下是 18），留着旧值比清空更危险。
  - 预览区实时显示四行：原始值、工程值、位模式、
    按本点字节顺序排好的寄存器序列（如 0xF5C3 0x4048）。
    按下「写入」前就能核对到底会发出什么。
  - 工程值口径下还显示反算公式，例如「原始值 = (工程值 − 5) ÷ 0.1 = 75」。
  - 反算结果落不到寄存器精度上时会提示（整数类型出了小数会就近取整，
    Float32 会被截断）；超出范围（如 UInt16 反算出负数或大于 65535）直接拦下。
  - 批量写入（功能码 16）填的是原始值。

【多通道同屏显示】
  左侧通道列表每行前面有一个复选框：
  - 点通道行 = 「只监视它」（原来的单选习惯）
  - 勾复选框 = 把通道并入监视集合，点表会同时显示多个通道的点
  - 标题变「点表 — 监视 N 点 / 多通道」，多出「通道」列
  - 鼠标悬停地址列会弹出十进制 / 十六进制 / PLC 三种写法
  - 「新增点 / 导入 / 导出」始终作用在「主通道」（标题里会写明是哪个）
  - 批量写入仍只能在同一通道内（功能码 16 是一帧写多个寄存器，跨串口不行）

【点位批量导入】
  「导入 CSV」→「下载模板」按格式填好再导回来。
  - 支持 UTF-8（Excel 另存 UTF-8 CSV）与 GBK（Excel 默认另存），逗号或分号分隔
  - 按表头识别列，列顺序可以调；缺列用默认值补
  - 三种方式：追加 / 合并（名称+地址相同的更新，曲线和历史不断）/ 覆盖
  - 坏行会跳过并列出行号与原因，好行照常导入
  - 「导出定义」导出的文件可以直接再导入
  - 「字节顺序」列可填 CDAB / ABCD / BADC / DCBA，也认「大端」「小端」；
    留空或旧文件没有这一列时按 CDAB 处理

【查看通信报文】
  底部切到「通信报文」标签页，串口上真实收发的每一帧都在这里，1 秒自动刷新。

  列表每一行是一条报文：时间、方向（发送/接收）、通道、从机号、功能码、
  报文十六进制、摘要、说明、字节数。

  - 单击一行 = 复制这串十六进制，可以直接粘到串口调试助手里重发
  - 双击一行 = 打开详情，逐字段看：从机地址 / 功能码 / 异常码 / 各数据域字段 / CRC
  - 「只看异常」一键滤出有问题的帧（CRC 错、地址或功能码不符、超时、异常响应）
  - 按通道、按方向（发送/接收）、按关键字过滤；关键字同时匹配报文与摘要
  - 「导出 CSV」把当前过滤结果存下来（含 ASCII 与摘要），便于发给设备厂家

  三种底色：无底色=正常；黄底=CRC 错、从机地址或功能码不符（会自动重试，还有救）；
  红底=从机返回异常响应、或超时没收到完整响应。

  排查时最有用的两个细节：
  - 超时也会把"已收到的那几个字节"记下来，显示成「残帧（只有 N 字节）」。
    从机回了半截就断，看这个一眼就知道。
  - CRC 校验失败时，详情里会同时给出"帧内的 CRC"和"算出来的 CRC"，
    能区分是线路干扰还是从机算错。

  报文只在内存里滚动保留最近 2000 条，写满了覆盖最旧的，程序退出即清空。
  要留存就点「导出 CSV」。工具栏会显示"共 N / 2000 条 · 发 X 收 Y · 异常 Z"。

【报警与联动】
  点位参数里配置：上限、下限（留空表示不判这个方向）、回差、确认延时、
  联动写入点位与值。
  - 回差：超上限后要回落到「上限 − 回差」以内才算恢复，防止临界抖动
  - 确认延时：持续超限 N 秒才报警，0 表示立即
  - 联动写入：报警触发那一下把预设值写进另一个可写点位（功能码 06/16），
    只在触发时写一次，不会反复写
  - 报警行整行染色，「报警」标签页可确认 / 全部确认 / 清空 / 导出 CSV

【曲线与历史】
  - 「曲线」：单点位实时曲线，窗口 1/5/15 分钟或全部，可暂停、清空、导出
  - 点表勾选多个点后「对比曲线」：最多 8 条曲线叠加，可开双 Y 轴、
    可叠加显示各点的报警上下限虚线
  - 「历史回放」：选点位 + 时间范围查询，可导出 CSV、清理单点位
    或清空整个历史库，也能设置保留天数与容量上限（超限时自动从最旧的分片开始删）
  - 落库默认是开着的（保留 30 天 / 上限 512 MB），启动采集后即开始记录。
    关掉的话，历史对话框顶部会出提示条，说明曲线与落库是两套东西
    （曲线走内存缓冲，不受落库开关影响，所以会出现"曲线有数据、历史查不到"）
  - 落库只对同时启用了「采集」与「曲线记录」的点位生效

【常见问题】
  - 串口打不开：检查 COM 口号、是否被其他软件占用
  - 采集无数据：确认从机 ID、寄存器地址、波特率、校验位与从机一致
  - 浮点数显示不对：多半是字序问题，切到「寄存器」口径看原始寄存器，
    CDAB 的点会看到低字在前
  - 采集一直报超时/CRC 错：切到「通信报文」看真实收发内容，
    确认从机号、功能码、地址是不是发出去了，从机回的是什么
  - 历史查不到数据：先看历史对话框顶部有没有「落库未开启」提示条；
    落库开着的，再确认该点位勾了「启用采集」和「曲线记录」，
    以及查询的时间范围是否覆盖到采集时段
  - 报警不触发：检查是否勾了「启用报警」且填了上限或下限，
    以及采集质量是否为 Good
